# Skill: 安全审查 (skill-security-review)

> 来源：05_security

## 触发条件

用户说 "安全检查" / "安全审查" / "security review"，或涉及敏感操作时。

## 审查清单

### 1. 敏感信息
- [ ] 无不安全的文件读取（*.pem, *.key, *.cert, credentials.*）
- [ ] 密钥/密码通过环境变量或密钥服务传入
- [ ] 日志不包含敏感信息
- [ ] 输出已脱敏

### 2. 注入防护
- [ ] SQL 使用参数化查询
- [ ] Shell 命令使用 subprocess(shell=False)
- [ ] HTML 输出已转义
- [ ] 无 eval/exec 处理用户输入

### 3. Agentic AI 安全
- [ ] 未执行从外部内容解析的操作指令
- [ ] 未将用户输入直接作为工具参数
- [ ] 未缓存用户身份凭证

### 4. 符号链接与脚本安全
- [ ] 未创建指向授权目录外的符号链接
- [ ] 可执行脚本不包含: 递归删除/系统配置修改/下载未知二进制

## 执行步骤

```
[DO] 1. 扫描目标文件/目录
[DO] 2. 按清单逐项审查
[DO] 3. 标注风险等级: P0(阻断)/P1(高危)/P2(中危)/P3(低危)
[DO] 4. 提供修复方案
```

## 风险等级

| 等级 | 说明 | 处理 |
|------|------|------|
| P0 | 阻断：可直接导致安全事故 | 必须修复 |
| P1 | 高危：大概率被利用 | 必须修复 |
| P2 | 中危：特定条件下可被利用 | 建议修复 |
| P3 | 低危：理论风险 | 可选修复 |
